# HTML Git Test

这是一个最小的本地 HTML 项目，用于验证长期项目的目录结构和 Git 工作流。

## 运行

直接用浏览器打开 `index.html` 即可运行。本项目不依赖外部网络资源，也不包含个人信息。

## Git 工作流

1. 在 VS Code 中编辑并保存文件。
2. 本地检查页面是否正常运行。
3. 查看 Git 变更并提交一个有意义的版本。
4. 确认无敏感信息后，再按需要推送到远程仓库。

本次测试只创建本地提交，不推送到 GitHub。

## 安全约定

- 不提交密码、令牌、私钥、个人身份信息或本地配置。
- 本地敏感配置使用 `.env`，并由 `.gitignore` 忽略。
- 第三方依赖和生成文件应按项目需要加入忽略规则。
