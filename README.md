# HTML Git Test

这是一个用于验证长期项目工作流的本地 HTML 项目。当前版本加入了本地任务清单、任务统计和主题切换，用来测试一次完整的功能迭代。

## 运行

直接用浏览器打开 `index.html` 即可运行。本项目不依赖外部网络资源、第三方库或构建工具。

## 当前功能

- 添加、完成和删除任务。
- 显示任务总数、完成数和完成率。
- 切换浅色/深色主题。
- 使用浏览器本地存储保存任务和主题偏好。
- 使用文本节点渲染用户输入，避免把输入当作 HTML 执行。

## 本地检查清单

1. 打开 `index.html`，确认页面正常显示。
2. 添加一条任务并标记完成，检查统计数字是否更新。
3. 删除任务，确认任务列表和统计数字同步更新。
4. 切换主题并刷新页面，确认偏好仍然保留。
5. 检查项目变更和敏感信息后再创建 Git 提交。

## Git 工作流

1. 在 VS Code 中编辑并保存文件。
2. 本地运行并检查功能。
3. 查看 Git 变更、差异和敏感信息。
4. 使用清晰的提交信息保存一个可回退的版本。
5. 确认内容无误后，再按需要推送到远程仓库。

## 安全约定

- 不提交密码、令牌、私钥、个人身份信息或本地配置。
- 本地敏感配置使用 `.env`，并由 `.gitignore` 忽略。
- 本页面的任务数据只存储在当前浏览器，不会发送到网络。
- 第三方依赖和生成文件应按项目需要加入忽略规则。
